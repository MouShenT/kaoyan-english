## 英语一专项讲解

### 长难句

原句 → 谓语与主干 → 从句/非谓语/插入语边界 → 修饰与指代 → 逻辑关系 → 自然中文译文。
保持原句不改写后冒充原文。that/which/it 的指代若需上下文，明确缺口。区分语法可行与语境合理；别把所有长修饰语都叫定语从句。

### 词汇

先讲当前语境义、词性和搭配，再给一两个常见义及易混点；不堆词典所有释义。不确定的词源不编造。例句自编要标明；给填空或替换练习检验语境运用。

### 阅读、完形、新题型、翻译

用原文具体句子解释证据链，比较选项的偷换对象、范围扩大、因果颠倒等；逐项诊断必须有原文，不能只凭“答案是 A”反推。翻译先保留逻辑再润色中文。

### 作文

先核对题目、受众、文体、字数要求和用户原文；小作文看任务完成、格式和语气，大作文看图意/观点、展开和衔接。
按“原句 → 修改 → 原因”优先改最影响意思的 2–3 处，提供尽量保留用户表达的版本；需要时再提供提高版。
未取得对应考纲评分依据，不冒充官方阅卷打精确分数。估分只能按明示的非官方维度给范围并说明不确定性。
推荐练习以改写自己的错句、同结构造句、短段落重写为主，不默认安排背模板或完整每日计划。


## 你可以直接这样问

- “我发一张题目照片，先只给一个提示。”
- “这是我的解题步骤，请指出第一个错误，给一两道变式。”
- “我还是分不清这个概念，结合资料举例说明。”
- “把这次问题整理成简短错题交接卡。”

英语仓库还支持长难句结构、语境词义、翻译与作文逐句修改。

## 能力边界

仓库提供资料与助手工作规则，回答由你正在使用的聊天模型完成。普通 ChatGPT 不会因为仓库存在而自动载入资料或保存跨聊天错题；请按手机指南连接 GitHub、读取规则并附题目。生成讲解不能冒充官方解析，机器提取不能冒充校对版。
